# Источники программы и открытые вопросы

Общая сетка взята из «Программа форума (Приложение).docx». Детальные события, спикеры и залы — из «Программа 2026.xlsx». Схема из сообщения организатора задаёт семь точек «Мы едины»: Незабудки, Дебаты, Вкурсе, Киберспорт, Квиз, Мастерская души, Настолки.

Требует согласования (пометки показаны и в интерфейсе):

- В DOCX завершение 17:00, конкурс добровольцев в Excel 16:00–18:00. Слот сохранён с пометкой; общий статус форума после 17:00 соответствует DOCX.
- «Мы едины» в Excel 12:00–14:30, 15:00–17:00, общая сетка DOCX 12:30–14:00, 14:30–17:00. Детальные интервалы сохранены.
- Схема содержит «После пленарки с 11:00 — демонтаж», но пленарное заседание в DOCX 11:30–12:30. График точек НЕ придуман, указан как уточняемый.
- У добровольческих активностей смешанные/объединённые ячейки с залами, часть данных относится к другому мероприятию. Такие локации помечены как требующие подтверждения.
- Внутренние технические потребности, телефоны и организационные комментарии из Excel не публикуются как программа для участников. Предложение «что-то ещё» не превращено в выдуманное событие.

Новая эмблема представлена SVG-реконструкцией по референсу. Городской фон — векторный силуэт Московского района по мотивам фотографии; это не оригинальная фотография и не исходный официальный логотип. Для точной печатной айдентики можно заменить SVG исходными файлами организатора.

## Уточнения организатора после сверки

Последнее сообщение организатора имеет приоритет над приложениями: все события добровольчества в кабинете 202; конкурс 16:00–18:00 удалён (будет в другое время); «Мы едины» — 12:30–14:00 и 14:30–17:00 в банкетном зале. Семь точек перечислены в описании интерактивной выставки основной программы, отдельный блок точек удалён. Все служебные пометки об уточнении и демо-время убраны из интерфейса.
